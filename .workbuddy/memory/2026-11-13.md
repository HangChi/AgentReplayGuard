### 004 实现完成（24 任务全绿）
- 实现阶段实测**推翻了 research 初稿两个结论**，已回改文档：
  1. LangGraph 1.2.20 同步 fan-out 是**线程池真并发**（节点 b/c 不同线程交错执行），非"顺序调度"；
     异步 fan-out 是协程交错。effect 追加 `sequence` 顺序抖动（`[c,b]`/`[b,c]` 交替）。
  2. 但**检测结论不依赖追加顺序**（NoDuplicateEffects 用 sorted/set、ConcurrentCommitDetected 用区间重叠），
     故确定性承诺收缩为「branch 归属 + 检测结论确定」，追加顺序标注为不确定（宪法 II）。
- branch_id 来源：`langgraph.config.get_config()['metadata']['langgraph_node']`（节点名），
  并发节点内正确隔离。**contextvar 被否决**（父线程值会被线程池子线程继承，无法区分分支）。
  通过「可注入 branch_resolver」隔离框架依赖（核心模块不 import langgraph）。
- 语义澄清：branch_id = 产生 effect 的节点名（串行图也记录节点名），None 仅限非 LangGraph 上下文。
- 版本 0.3.0 → 0.4.0。
- 新增：EffectRecord.branch_id 字段；ConcurrentCommitDetected 不变量（started/ended_tick 区间重叠）；
  strict_graph 语义反转（True=支持 fan-out，False=仅警告）。
- 新增示例 examples/refund/graph_parallel.py + test_refund_parallel.py。

### ⚠️ 发现的既有 bug（待修，未在 007 修复）
- `@guard.effect(..., idempotency_key="idempotency_key")` 装饰的函数若**本身有同名参数**
  `idempotency_key`，且调用时**用关键字传参**，会触发 `TypeError: got multiple values for
  keyword argument 'idempotency_key'`。
- 根因：call/acall 的 idempotency_key 配置参数名与函数实参 kwargs 里的同名 key 冲突。
- 现有代码用「位置参数传幂等键」绕开（test_guard.py 第 54 行有注释），但 OpenAI SDK 用
  kwargs 传工具参数，会必然触发。
- 彻底修复需重构 call/acall 参数传递机制，风险较高，未夹带在 007。建议单独开一个 bugfix
  阶段处理。
